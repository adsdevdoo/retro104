# Этап 2: варианты звуковой карты PC/104

Исходные условия: хост — PCM-3864 (386SX-40, ISA через PC/104, BIOS AMI 1996); на разбор есть
несколько карт **BTC 1853L** (ISA 16 бит, ревизия на фото — REV:B). Документы и фото — в
[`datasheets/`](datasheets/) и [`references/photos/`](references/photos/), ссылки — в [sources.md](sources.md).

## Что есть на донорской BTC 1853L

По фото платы REV:B (theretroweb, автор oerg866) и паспорту карты на theretroweb:

| Позиция | Деталь | Пригодность для PC/104 |
|---|---|---|
| U3 | **ESS ES1868F AudioDrive**, PQFP-100 | основа карты |
| Y1 | кварц **14.31818 МГц**, HC-49 | нужен ES1868 (даташит, t14: 14.318 MHz) |
| U4 | **Atmel 93C66**, DIP-8 | PnP-EEPROM ES1868 (даташит, рис. 15: 93LC66, 512 × 8) |
| — | **CM2025B** (аналог TEA2025), DIP-16 | стереоусилитель на динамики, по желанию |
| U2 | 74LS138 | дешифратор для IDE на карте; на PC/104 не нужен |
| J9, J8 | IDE 40-pin, wavetable 2 × 13 | на PC/104 не нужны (IDE есть на хосте, wavetable-дочка не входит по высоте) |
| — | 3 гнезда 3.5 мм, DB-15 game/MIDI, разъёмы CD-in | заменить на низкопрофильные гнёзда/штыревые разъёмы |

Свойства ES1868 по [даташиту](datasheets/ess-es1868-datasheet.pdf):
- Совместим с Sound Blaster, Sound Blaster Pro 3.01 и OPL3. Встроены 20-голосный FM ESFM (совместим по регистрам с OPL3), 16-битные ADC/DAC до 44.1 кГц, MPU-401 (UART) и game-порт.
- Шина данных **8 бит** (D[7:0]), декодирует адреса A[11:0] с AEN.
- 6 выходов IRQ (IRQA–F) и 4 пары DRQ/DACK. На какие линии ISA они разведены, решает плата, а сообщает их ES1868 запись в EEPROM. Пример в даташите: IRQ 9/5/7/10/11/12, DMA 0/1/3/5.
- PnP встроен. Для системы без PnP есть «bypass key» через порт 279h: им конфигурацию включает DOS-утилита ESS.
- Питание 5 В (или 3.3 В). Для аналоговой части даташит показывает отдельный 78L05.

## Варианты

### A. Своя PC/104-карта на ES1868F с донора — рекомендую

С донора снимаются ES1868F, кварц, 93C66 и при желании CM2025B. Схема строится по типовому включению
из даташита, только аудио без IDE и модема. На плате — разъёмы PC/104 из `pc104-blank` и отверстия
по стандарту.

- **Плюсы.** Все ключевые детали уже есть, причём на несколько плат. Один чип даёт SB Pro, FM,
  MPU-401 и джойстик. Шина 8-битная, буферы не нужны. Есть драйверы того времени для DOS, Windows 3.1
  и 95 (theretroweb). Для 386SX это родной уровень: игр под SB Pro и OPL3 хватает.
- **Минусы.** Не SB16: 16-битный DMA SB16 не поддерживается, игры переходят на режим SB Pro. ESFM
  по регистрам совместим с OPL3, но, по опыту ретро-сообщества, часть FM-музыки звучит иначе, чем
  на Yamaha YMF262; в этой работе это не проверялось. Нужно аккуратно снять QFP-100 феном и
  развести аналог по рекомендациям даташита (прил. C).
- **На PCM-3864.** Отдельной PnP-настройки в руководстве нет. Поэтому в DOS карту включает утилита
  ESS из `AUTOEXEC.BAT`; Windows 95 настраивает её сама. Ресурсы: SB 220h / IRQ5 / DMA1, MPU-401 330h,
  FM 388h, джойстик 201h. LPT хоста держать на IRQ7, а DMA ECP — на 3 (руководство PCM-3864, с. 16:
  у LPT выбор IRQ5/7, у ECP — DMA1/3). Порты сторожевого таймера 443h/043h с ES1868 не пересекаются:
  ему нужны нулевые A11:10.
- **Шина.** Сам ES1868 обходится J1 (IRQ5/7/9, DMA1/3). J2 всё равно ставим проходным: он даёт
  IRQ10/11/12/15 и DMA0 и пропускает 16-битную шину к Ethernet-модулю. По стандарту 8-битный модуль
  без J2 должен стоять в стеке выше 16-битных (PC/104 v2.6, разд. 2.2).

### B. Переходник PC/104 → слот ISA и донорская карта целиком

Небольшая плата: проходные PC/104 и 16-битный слот ISA (98 конт.), в слот вставляется BTC 1853L как есть.

- **Плюсы.** Почти без риска и быстро. Сразу проверяет, как ES1868 и утилиты ESS ведут себя на
  PCM-3864 (BIOS, ресурсы, DOS), ещё до перепайки чипов. Тот же переходник пригодится для проб
  ISA-сетевых карт к этапу 3.
- **Минусы.** Не компактно: полноразмерная ISA-карта торчит из стека, нужна механическая опора.
  Слоту нужны +12 В, а при желании −5/−12 В: на шину PC/104 их подаёт PCM-3864 через CN13/CN8,
  если они подключены. Как самостоятельная звуковая карта — временное решение.

### C. Порт PicoGUS (RP2040) на формат PC/104

[PicoGUS](https://github.com/polpo/picogus) — открытая ISA-карта на RP2040. Железо — CERN-OHL-P v2,
прошивка — GPL v2. Эмулирует GUS, AdLib (OPL2), Sound Blaster 2.0 (в новых прошивках есть SB Pro
stereo), MPU-401, Tandy и CMS.

- **Плюсы.** Детали современные, их можно купить. Есть Gravis UltraSound, прошивка обновляется,
  проект живой (последние изменения — ноябрь 2026).
- **Минусы.** Нет OPL3, а SB — эмуляция. Донорские карты не используются. Перенос на 90 × 96 мм
  с ограничением высоты 11 мм и согласованием 5 В ↔ 3.3 В — отдельная серьёзная работа, и на
  386SX/PC/104 её надо проверять заново.

### D. Другие чипы той эпохи (Yamaha OPL3-SA3 YMF715, Crystal CS4237B)

Тоже «один чип»: SB Pro, WSS и FM; у YMF715 FM настоящий Yamaha OPL3. Но чипы пришлось бы покупать
б/у. Перед вариантом A у них есть одно преимущество — настоящий OPL3 у YMF715 — а дополнительные
поиск и проверка деталей его съедают.

## Решение

**Вариант A.** Владелец проверяет донорские BTC 1853L сам, отдельно (решение 2026-11-15), поэтому
стенд по варианту B не делается. Своя PC/104-карта собирается на ES1868F, кварце и 93C66 с
проверенного донора.

Решения владельца для варианта A (2026-11-15):

1. **Выход — только линейный.** Усилитель CM2025B/TEA2025 не ставится.
2. **Разъёмы:** низкопрофильные гнёзда 3.5 мм на краю платы для аудио, game/MIDI — штыревой 2 × 8
   под стандартный кабель на планку DB-15. Обычный угловой DB-15 выше допуска PC/104 в 11.05 мм.
3. **Входы:** Line-in (стерео) и Mic (моно). CD-in не нужен.
4. **Питание аналога** — от +5 В шины PC/104 через фильтр. +12 В карте не нужно.

Не ставятся также IDE, модем, wavetable-разъём и дешифратор 74LS138 донора. С донора берутся
ES1868F, кварц 14.31818 МГц и EEPROM 93C66.
