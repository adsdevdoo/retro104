# Изготовление pc104-blank rev A

Статус: **файлы готовы и проверены программно, плата не заказывалась и в железе не проверялась.**
Заказ, оплату и загрузку файлов выполняет владелец.

Архив для заказа: [`hardware/pc104-blank/fabrication/pc104-blank-revA-jlcpcb.zip`](../hardware/pc104-blank/fabrication/pc104-blank-revA-jlcpcb.zip).
Внутри 7 Gerber (медь, маска и шелкография с двух сторон, контур) и 2 Excellon (PTH и NPTH).
NPTH пустой — неметаллизированных отверстий нет. Карты сверловки PDF лежат рядом, в `gerbers/`,
и `.drl` не заменяют.

| Параметр заказа | Значение |
|---|---|
| Габарит по Edge.Cuts | **95.89 × 90.17 мм** (3.775 × 3.550 in), прямые углы, как в стандарте |
| Материал, слои | FR-4, 2 слоя |
| Толщина | 1.6 мм (стандарт PC/104 — 0.062 in = 1.57 мм) |
| Медь | 1 oz |
| Покрытие | HASL lead-free достаточно (только THT); ENIG — по желанию |
| Маска / шелкография | зелёная / белая, обе стороны |
| Отверстия | 104 × Ø1.02 мм PTH (контакты), 4 × Ø3.18 мм PTH (крепёж); переходных нет |
| Особые технологии | нет: ни ламелей, ни импеданса, ни castellated |

После загрузки в просмотрщик фабрики проверить:
- 95.89 × 90.17 мм, два слоя меди;
- 108 отверстий;
- квадратные площадки A1 и C0 у правого края при виде сверху;
- надпись «PC/104» сверху;
- зеркальные надписи снизу.

## Что проверено

| Проверка | Результат |
|---|---|
| ERC | 0 ошибок, 0 предупреждений ([erc.rpt](../hardware/pc104-blank/reports/erc.rpt)) |
| DRC + соответствие схеме | 0 нарушений, 0 неподключённых, 0 ошибок футпринтов ([drc.rpt](../hardware/pc104-blank/reports/drc.rpt)) |
| Контакты против PC/104 v2.6 и Advantech | 104/104 на местах, имена совпадают, отличия только B10/C19 ([pinout-check.md](../hardware/pc104-blank/reports/pinout-check.md)) |
| Gerber/Excellon | контур, 108 отверстий и их диаметры пересчитаны из файлов и сверены со стандартом ([fab-check.md](../hardware/pc104-blank/reports/fab-check.md)) |
| Шелкография | рендеры верха и низа просмотрены целиком: подписи не перекрываются, не лежат на площадках и в пределах платы |

## Что не проверено

- DFM-проверка JLCPCB и просмотр в её онлайн-просмотрщике.
- Примерка на PCM-3864: совпадение стоек с отверстиями хоста и заглушки B10/C19 ([mechanics.md](mechanics.md)).
- Наличие ESQ-132-39-G-D / ESQ-120-39-G-D у поставщиков: у Samtec деталь помечена как доступная
  существующим клиентам. Подходит любой проходной разъём PC/104 с квадратным штырём 0.64 мм.

Не заказывать, не оплачивать и не загружать файлы без поручения владельца.
