# pc104-blank rev A

Пустая механическая плата-ответка PC/104 для PCM-3864 (этап 1). Проект для **KiCad 9.0.2 или новее**:
откройте `pc104-blank.kicad_pro`.

| Файл | Что это |
|---|---|
| `pc104-blank.kicad_sch` | схема: CN2 (J1/P1), CN1 (J2/P2), H1–H4; все выводы помечены как неподключённые |
| `pc104-blank.kicad_pcb` | плата 95.89 × 90.17 мм, 2 слоя, без дорожек и цепей |
| `../lib/retro104.kicad_sym` | символы PC104_J1P1, PC104_J2P2, MountingHole_PC104 |
| `../lib/retro104.pretty/` | футпринты разъёмов PC/104 и крепёжного отверстия |
| `../lib/3d/` | иллюстративные VRML-модели ([docs/models.md](../../docs/models.md)) |
| `reports/erc.rpt`, `reports/drc.rpt` | ERC и DRC с проверкой соответствия схеме |
| `reports/pinout-check.md`, `reports/fab-check.md` | сверка контактов и файлов производства |
| `fabrication/` | Gerber, Excellon, карты сверловки, архив для JLCPCB, `SHA256SUMS` |

Статус: **ERC 0, DRC 0 (0 неподключённых, 0 расхождений со схемой), 104/104 контакта и 4/4
отверстия совпадают со стандартом, Gerber/Excellon проверены. Не изготавливалась.**

Каждый контакт сидит в собственной цепи `unconnected-…`: так KiCad помечает выводы с флагом «не
подключено». Электрических соединений между площадками нет. Отверстия H1–H4 металлизированы,
но к цепям не подключены.

Футпринты повёрнуты как на рис. 3 PC/104 v2.6: разъёмы у правого края, pin 1 внизу. Начало координат
футпринта — A1 (J1/P1) и C0 (J2/P2). Контур шелкографии J2/P2 со стороны J1/P1 не рисуется: корпуса
по стандарту разделяет всего 0.127 мм, и общий край рисует J1/P1. Ключевые позиции B10 и C19
отмечены на слое F.Fab. Пересборка — `python tools/make_all.py` из корня репозитория.
