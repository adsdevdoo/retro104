# pc104-audio rev A

Звуковая карта PC/104 на ESS ES1868F (этап 2). Описание схемы, ресурсов и разъёмов —
[docs/pc104-audio.md](../../docs/pc104-audio.md). Проект для **KiCad 9.0.2 или новее**:
откройте `pc104-audio.kicad_pro`.

| Файл | Что это |
|---|---|
| `pc104-audio.kicad_sch` | схема, один лист A2: каждый вывод с меткой цепи, неиспользуемые — с флагом NC |
| `pc104-audio.kicad_pcb` | плата 95.89 × 90.17 мм, 2 слоя, разведена FreeRouting 2.5.0, GND залит с двух сторон |
| `../lib/` | общая библиотека: символы, футпринты (свои и копии KiCad 9), 3D-модели |
| `reports/erc.rpt`, `reports/drc.rpt` | ERC и DRC с проверкой соответствия схеме |
| `reports/netlist-check.txt` | нетлист против `tools/audio_design.py` |
| `reports/fab-check.md` | контур, CN1/CN2 и отверстия по стандарту, сверловка против платы |
| `fabrication/` | Gerber, Excellon, карты сверловки, архив для JLCPCB, `SHA256SUMS` |
| `../../docs/pc104-audio-assembly.pdf` | сборочный чертёж: верхняя шелкография и слой F.Fab (контуры корпусов) |

Статус: **ERC 0; нетлист = `audio_design.py`; FreeRouting — 0 неразведённых; DRC 0 нарушений,
0 неподключённых, 0 ошибок футпринтов; файлы производства проверены. В железе не проверялась.**

Как получена плата:

1. `tools/audio_design.py` — детали, цепи и неподключённые выводы.
2. `tools/gen_audio.py` — схема; `kicad-cli sch export netlist` — нетлист.
3. `tools/check_audio_netlist.py` — нетлист против `audio_design.py`.
4. `tools/build_audio_board.py` — расстановка и DSN.
5. FreeRouting 2.5.0 — трассировка.
6. `tools/route_audio_board.py` — импорт трассировки, земля, сшивка.
7. `tools/audio_silk.py` — шелкография обеих сторон.

Всё это делает `python tools/make_all.py --route-audio`. Без флага плата не перетрассируется:
выполняется только шаг 7, затем проверки и выгрузка. Шаг 7 меняет только шелкографию и при повторном
запуске даёт тот же файл.

Шелкография:

- **Верх.** Обозначения всех деталей, 1.0 мм. У микросхем, кварца и электролитов указан номинал:
  ES1868F, 74HCT138, 93C66, 14.318MHz, 10u/47u. Место для подписи скрипт ищет сам: не ближе
  0.2 мм к площадкам и другой шелкографии, не на чужих корпусах, не ближе 0.5 мм к краю. Номиналы
  0805 — в схеме.
- **Низ.** Рамка с названием. Таблица соответствия линий IRQ/DRQ ES1868 линиям ISA. Типовые ресурсы
  PnP. Назначение перемычек JP1/JP2. Сведения о гнёздах. Названия выводов J4 у каждой площадки.
  Подписи CN1/CN2 и ссылка на репозиторий.
